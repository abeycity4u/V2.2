# V2.2.18 Dependent Attribution Filters

- Profitability Farm Type now immediately rebuilds Production Type options.
- Profitability Production Cycle is a dependent selector: Farm Type -> Production Type -> Cycle.
- Changing a parent resets an incompatible child to All/Pooled instead of retaining stale attribution.
- Sales Report Farm Type now refreshes Production Type consistently.
- Expense Report Farm Type now refreshes Production Type consistently, and Production Type now triggers the report filter.
- General remains a first-class Farm Type and maps to General attribution.
- No database migration is required.
