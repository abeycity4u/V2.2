# V2.2.13 — Feed Table Consistency

UI-only stabilization for Layer, Broiler and Ruminant Monthly Transactions tables.

- Adds the missing Broiler `Unit` header so header/body column counts match.
- Standardizes headers to Date, Feed Item, Type, Quantity, Previous Stock, New Stock, Unit, Remarks, Origin, Recorded By, Actions.
- Prevents DataTables from collapsing/shrinking the header by using a stable minimum width and disabling automatic width calculation.
- Standardizes 25-row default, descending date sort and responsive priorities across all three feed modules.
- No database migration is required.
