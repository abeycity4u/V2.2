# V2.2.23 — Archive, Audit View & Dark Mode

Built on V2.2.22 inventory/expense cleanup.

## Improvements
- Archived inventory moved out of the main dashboard table into a compact Archived Items manager modal.
- Historical items remain protected and restorable; active stock/feed operations reject inactive items at the canonical stock service.
- Layer, Broiler and Ruminant feed stock cards list active items only.
- Feed transaction ledgers open in Operational View; Full Audit reveals reversed originals/restoration rows without changing the effective monthly summary calculation.
- Added persistent Light/Dark mode toggle under Account using local browser preference.
- Profitability filter controls align on one row; Production Type explanation is now a shared helper below the filter row.
- Existing V2.2.22 expense form consistency and notification timing retained.

No database migration required.
