# V2.2.16 — Historical Cost Integrity

This release hardens profitability against frequent inventory price changes without rewriting historical business results.

- Existing stock transaction `unit_cost` and `total_cost` snapshots remain the financial source of truth.
- Used stock now derives its snapshot from effective weighted-average ledger history on the business date when possible, protecting back-dated Daily Record corrections from later replacement prices.
- Effective-ledger valuation can re-align `stock_items.unit_cost` after reversals/corrections without changing immutable historical transaction snapshots.
- Inventory receipts now require an explicit receipt price instead of silently inheriting a potentially stale current cost.
- Profitability feed cost is restricted to actual feed inventory; vaccines/other stock can no longer be mislabeled as feed in broad reports.
- Sales continue to use recorded `unit_price/total_amount`; operating expenses continue to use their recorded amount and unit, so later market price changes do not rewrite old records.

No database migration is required because the transaction cost snapshot columns were introduced in migration 014.
