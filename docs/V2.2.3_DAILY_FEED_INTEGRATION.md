# V2.2.3 — Integrated Daily Feed Consumption

Daily operational records now include an **Active Feed Item** selector directly below Feed Consumption.

## Modules
- Layer Daily Record
- Broiler Daily Record
- Ruminant Daily Record

## Behavior
- Only active, farm-compatible feed items for the relevant module are listed.
- Feed consumption greater than zero requires a feed item.
- Saving a daily record creates/updates one linked inventory `used` transaction.
- Editing a daily record reverses the previous linked inventory usage before applying the new usage.
- Deleting a daily record restores the linked inventory quantity and removes the linked transaction.
- Linked transactions use `source_type` + `source_id` so the financial engine can trace consumption back to the daily record.
- Ruminant daily records retain the selected feed item's unit in `feed_consumption_unit`.

## Database migration
Run:

`migrations/015_daily_feed_integration.sql`

after the V2.2 financial foundation migration (`014_v22_financial_foundation.sql`).

## Safety
The daily-record save and inventory synchronization are performed in one database transaction. If inventory validation fails (for example, insufficient stock), the daily record is rolled back as well.
