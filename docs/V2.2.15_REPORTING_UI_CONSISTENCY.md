# V2.2.15 — Reporting & UI Consistency

- Added shared `stock_effective_sql_predicate()` so feed quantity reporting and profitability use the same reversal-safe eligibility rule.
- Profitability now supports **Daily** and **Monthly** analysis with one calculation engine.
- Daily profitability uses the selected date as both start and end date; monthly uses the full selected calendar month.
- Feed consumption remains consumption-cost based. Feed purchases remain visible as cash expenses but are not double-counted as operating feed cost.
- Uncosted-feed warning now respects farm type and production cycle filters.
- Layer, Broiler and Ruminant feed ledgers now use the same ⬆ / ⬇ movement indicators.
- No database migration required.
