# V2.1 Final Stabilization Audit

## Verdict

**V2.1 stabilization is functionally ready to freeze after the latest duplicate-cycle and notification hardening changes.**

The live test results supplied during QA covered the previously failing delete flows, layer cycle loading/edit/delete, feed stock validation, ruminant validations, custom confirmations, and species-scoped ruminant tags. The code audit below adds the remaining static/contract checks and closes the production-cycle duplicate-code issue.

## Latest finding fixed

### Production cycle code uniqueness

Cycle codes are intentionally unique **per farm**, not globally. The database migration uses:

`UNIQUE KEY uniq_farm_cycle_code (farm_id, cycle_code)`

Therefore:

- Farm A + `test2` = valid
- Farm B + `test2` = valid
- Farm C + `test2` = valid
- Farm A + `test2` a second time = rejected

The create-cycle flow now:

1. Validates the cycle code before insertion.
2. Checks for an existing code within the current farm.
3. Shows a friendly duplicate notification instead of a SQL error.
4. Preserves all other Create Cycle form values.
5. Keeps the database unique constraint as the final race-condition safeguard.
6. Converts a database duplicate (`1062`) into the same friendly message.
7. Never exposes raw SQL/PDO details to the user.

## Remaining engineering recommendations

These should be addressed during the appropriate later release rather than blocking V2.1 stabilization:

1. Make migrations the sole source of runtime schema changes; avoid compatibility DDL inside web requests.
2. Add database-backed integration tests with two seeded farms to prove tenant isolation across every endpoint.
3. Add browser smoke tests for the critical create/edit/delete workflows.
4. Introduce PHPStan/Psalm and CI linting.
5. Review destructive inventory-category semantics and prefer archive/soft-delete where appropriate.
6. Complete CSP work after inline scripts/styles are deliberately migrated.

## Deployment note

For a multi-tenant installation, migrations are authoritative. In particular, the current production cycle uniqueness and ruminant species-scoped tag behavior depend on the corresponding migrations being applied.
